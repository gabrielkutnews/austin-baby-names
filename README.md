# Austin baby names

Interactive graphics comparing Austin baby-name data across 2017–2024 and with
Texas statewide rankings. The self-contained HTML files in `docs/` are designed
for GitHub Pages and iframe embedding in Grove.

## Build

Run the complete R pipeline from the project directory:

```sh
Rscript run_all.R
```

The generated embed files are written to `docs/`.

## Published embeds

- `docs/embed-bubbles.html` — interactive baby-name trends
- `docs/embed-texas.html` — Austin and Texas rank comparison
- `docs/embed-table.html` — top-100 table
